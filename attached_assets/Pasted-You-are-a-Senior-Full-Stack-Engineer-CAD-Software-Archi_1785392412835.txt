You are a Senior Full-Stack Engineer, CAD Software Architect, Computer Vision Engineer, and AI Engineer.

Build a production-ready full-stack web application called **CAD AI Converter** that converts SketchUp (.skp), AutoCAD DXF/DWG, and structured 3D JSON into interchangeable formats while providing an AI-powered interactive browser viewer.

## Goal

Develop a modular platform where every imported file is converted into a **single canonical JSON model**, enhanced using AI to detect architectural elements, visualized in a browser, edited by the user, and exported back to SKP, DXF, or DWG.

The Canonical JSON must be the **single source of truth** throughout the application.

# AI Output

Each detected object should include:

- unique id
- object type
- confidence score
- geometry
- metadata
- dimensions

Example:

{
"id":"wall_001",
"type":"wall",
"confidence":0.98,
"geometry":{},
"properties":{
"length":5000,
"height":3000,
"thickness":200
}
}

If confidence is below a configurable threshold (e.g., 0.80), classify the object as "Unknown" and highlight it in the viewer for user review.
